# ADR-003: REST 快照与 WebSocket 实时更新并用

- Status: Accepted
- Date: 2026-09-27

## Context

纯 WebSocket 状态流在断线时可能丢事件；纯轮询又无法满足每秒行情和即时成交反馈。

## Decision

REST 是完整账户/行情快照的权威来源，WebSocket 推送行情和受影响用户的账户快照。客户端断线后采用 1、2、4、8、10 秒有界退避；重连成功必须先重新拉取 REST 快照，再显示“实时已连接”。

## Consequences

- 临时断线不会让前端永久停留在旧状态。
- 服务端必须按会话绑定 socket；集成测试明确验证用户间私有事件隔离。
- 当前没有事件序号或历史重放，因为完整快照足以恢复本题范围内的状态。
