# ADR-002: 使用整数分和显式资源冻结

- Status: Accepted
- Date: 2026-09-27

## Context

浮点金额会产生累计误差；仅在成交时检查余额会允许多个未成交委托重复占用同一笔资金或持仓。

## Decision

后端内部价格/资金全部使用整数分。买单进入订单簿前冻结 `限价 × 数量`，卖单冻结数量。成交时买方按实际成交价扣款、按原限价释放对应冻结额；价差自动回到可用资金。

## Consequences

- 可用资金与可用持仓始终可解释，拒单不会部分修改状态。
- API 在边界转换回两位小数金额。
- 当前没有撤单；加入撤单时必须释放剩余冻结资源并增加对应回归测试。
